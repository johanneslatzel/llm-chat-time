A typed TypeScript package providing datetime, timer, and stopwatch tools for the [`@johannes.latzel/llm-chat`](https://github.com/johanneslatzel/llm-chat) ecosystem.

## Prerequisites

- Node.js >= 18
- [`@johannes.latzel/llm-chat`](https://github.com/johanneslatzel/llm-chat)

## Installation

```bash
npm install @johannes.latzel/llm-chat-time
```
